- `generated-native/`: C++ hook/trace sources and compiled `.dll/.lib/.exp/.obj` outputs from reverse-engineering experiments.
- `screenshots-and-traces/`: screenshots, trace logs, and vendored Python reverse-engineering tools moved out of `work/`.

Runtime logs remain in `../work/`.
